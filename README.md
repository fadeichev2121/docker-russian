# Docker Desktop на русском

[![Лицензия: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Python: 3.9+](https://img.shields.io/badge/Python-3.9%2B-brightgreen.svg)](https://www.python.org/)
[![Версия: 2.1.1](https://img.shields.io/badge/Версия-2.1.1-blueviolet.svg)](manifest.json)

Русификатор интерфейса Docker Desktop со словарём из **3 290 фраз**. Перевод подключается через скрипт предзагрузки в архиве `app.asar`. Бинарные файлы движка Docker не изменяются.

## Важно для macOS

**Установка и автоматический откат на macOS в версии 2.1.1 заблокированы до любых изменений файлов.** Изменение `app.asar` и подписанного `Info.plist` может привести к `Code Signature Invalid`: пересчёт хеша Electron не сохраняет цифровую подпись приложения.

Предыдущий локальный вариант 2.1.0 привёл к отказу запуска Docker Desktop 4.93.0 (сборка 4.93.0.2). **Не устанавливайте архив 2.1.0.** Успешная пересборка архива и совпадение хешей не доказывают работоспособность приложения.

Восстановление одного `app.asar` не гарантирует исправления. Нужны оригинальные файлы приложения из официального установщика той же версии и сборки, включая точный исходный `Info.plist`. Дополнительные `.bak` и `.meta.json` внутри подписанного пакета тоже могут нарушать проверку ресурсов; храните резервные копии вне приложения. Не отключайте проверку подписей и не пересоздавайте подпись для обхода ошибки.

При восстановлении проверенного экземпляра Docker 4.93.0 оригинальными файлами строгая проверка подписи прошла, а интерфейс показал `Engine running`. Перевод при этом снят. Помощник для русификации без изменения подписанного приложения **ещё не включён в этот выпуск**.

## Совместимость

| Платформа | Состояние версии 2.1.1 |
| --- | --- |
| macOS | Установка и автоматический откат заблокированы; доступна проверка статуса |
| Windows | Экспериментальный установщик; запуск Docker с этим патчем не проверен |
| Linux | Экспериментальный установщик; запуск Docker с этим патчем не проверен |

Совместимость с произвольной версией Docker Desktop не гарантируется. После обновления Docker файлы интерфейса могут измениться. Старая резервная копия не подходит для отката новой версии.

## Изменения в 2.1.1

- Заблокированы операции записи на macOS, которые могут нарушить подпись приложения.
- Добавлены 94 перевода; учитываются переносы строк, неразрывные и граничные пробелы рядом со ссылками.
- Переводятся подсказки полей ввода; введённые значения сохраняются.
- При повторной установке метаданные резервной копии берутся из исходного архива.
- Откат отклоняет копию другой версии архива, копию без метаданных или с изменённым контрольным хешем. Сборка проверяется, если была определена при создании копии; без номера сборки проверка ограничена версией архива. При обновлении сохраняется отдельная старая копия.
- Запись отдельного файла атомарна. Обычная ошибка записи архива или `Info.plist` запускает восстановление предыдущих файлов; это не общая транзакция на случай отключения питания.
- Установка и откат требуют завершения Docker Desktop.

## Использование

Требуется Python 3.9+. Сначала загрузите репозиторий:

```bash
git clone https://github.com/fadeichev2121/docker-russian.git
cd docker-russian
```

### macOS

Доступна проверка наличия патча, без изменения приложения:

```bash
bash install.sh status
```

`install` и `restore` завершатся с сообщением о блокировке. Для восстановления повреждённого приложения используйте официальный установщик Docker той же версии и сборки. Проверка статуса не проверяет запуск Docker и валидность подписи.

### Linux (экспериментально)

Полностью закройте Docker Desktop, сохраните резервную копию установки и выполните:

```bash
bash install.sh install
```

Для записи в `/opt/docker-desktop` установщик может запросить права администратора. Откат архива из совместимой резервной копии:

```bash
bash install.sh restore
```

### Windows (экспериментально)

Откройте PowerShell в каталоге репозитория. Полностью закройте Docker Desktop. Для записи в `Program Files` могут потребоваться права администратора:

```powershell
powershell -ExecutionPolicy Bypass -File .\windows\install.ps1 install
powershell -ExecutionPolicy Bypass -File .\windows\install.ps1 status
powershell -ExecutionPolicy Bypass -File .\windows\install.ps1 restore
```

Откат возвращает исходный архив из резервной копии; запуск приложения после отката нужно проверить отдельно.

## Устройство перевода

`core/asar.py` читает и пересобирает ASAR без внешних зависимостей. `core/ui-runtime.js` отслеживает изменения интерфейса через `MutationObserver`. Области терминалов, логов, кода и редактируемого содержимого исключаются из перевода по DOM-селекторам; это ограничение требует проверки при изменении интерфейса Docker.

## Проверки выпуска

Семь автоматических проверок охватывают запрет записи на macOS, отклонение неподтверждённых резервных копий и возврат исходных файлов при обычной ошибке записи. Проверены синтаксис Python и JavaScript, shell-скрипты и количество фраз в словаре. Эти проверки не подтверждают запуск переведённого Docker на Windows или Linux.

```bash
python3 -m unittest discover -s tests -v
```
