# Понятная установка Docker Desktop на русском

Согласованный формат: терминальное меню, установка исходного Docker, понятный запуск и удаление перевода. Реализация продолжает согласованный в другом чате план запуска через CDP pipe; подписанные файлы не меняются. Ярлык запускает оригинальный Docker, а не копию приложения.

- [x] Добавить помощник Node.js 18+ без npm-зависимостей: установка в пользовательский каталог, закрытый CDP pipe, проверка app://dd, повторное подключение при навигации.
- [x] Разделить управление помощником и интерфейсом Docker; остановка касается только подтверждённого dashboard-процесса, движок не останавливается.
- [x] Добавить повторяемое терминальное меню: установить, открыть, статус, удалить, журнал, выход. Отдельные понятные ошибки отсутствия Node/Docker, неверной подписи и неудачного подключения.
- [x] Подключить тот же помощник на Windows/Linux экспериментально; не использовать старый ASAR-патч через основные установщики.
- [x] Сохранить исходный словарь. Сделать runtime идемпотентным, с остановкой и восстановлением строк; не переводить введённые данные, код и логи.
- [x] Проверить изолированные сценарии и синтаксис; реальный Docker пользователь проверяет самостоятельно. Не включать автозапуск без отдельного выбора.
- [x] README: две команды -> пункт 1 -> пункт 2; отдельные инструкции для трёх ОС, удаления, обновлений и восстановления старого повреждённого приложения.
- [x] Собрать локальный ZIP. Публикацию выполнять только по прямому разрешению пользователя.
